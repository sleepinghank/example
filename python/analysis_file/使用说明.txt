🎯 功能特性
-----------
✓ 支持文件格式：
  - 无CRC：projectname_country_v.v.v.yymmdd_release.bin
  - 有CRC：projectname_country_v.v.v.yymmdd_CRC_release.bin
✓ 自动提取：项目名称、国家代码、版本号、日期、CRC（可选）、发布类型
✓ release字段智能提取：自动忽略后缀（如_Encrypt），只保留核心类型
✓ 智能筛选：按项目、国家、版本、日期范围筛选
✓ 汇总统计：自动生成统计报告
✓ 数据导出：支持CSV格式导出
✓ 交互操作：提供交互式筛选菜单
✓ 递归扫描：支持扫描子文件夹

🚀 快速开始
-----------
1. 安装依赖
   pip install pandas

2. 编辑快速分析脚本
   修改 quick_analyze.py 中的 folder_path 变量：
   folder_path = r"D:\Data\Document\ProductsLibrary\C线产品资料库"

3. 运行分析
   python quick_analyze.py

4. 查看结果
   - 控制台显示汇总和详细信息
   - 自动生成 CSV 文件

📊 使用示例
-----------
# 基本使用
from file_analyzer import FileAnalyzer

analyzer = FileAnalyzer(r"D:\Data\Documents")
results = analyzer.analyze_files()
analyzer.print_summary()

# 筛选特定项目
kb_files = analyzer.filter_files(projectname="KB04122")

# 筛选日期范围
q1_files = analyzer.filter_files(date_start="240101", date_end="240331")

# 导出结果
analyzer.export_to_csv("results.csv")

⚠️  注意事项
-----------
1. 确保有权限访问目标文件夹
2. 文件名必须严格符合格式：projectname_country_v.v.v.yymmdd_release.bin
3. 日期格式为6位数字（yymmdd），如：240101 表示2024年1月1日
4. 需要 Python 3.6 或更高版本
5. Windows系统下建议使用英文路径避免编码问题
