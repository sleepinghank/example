## 详细说明

1. **平均刷新率**: 触控板每秒上报数据的平均次数，越高越好
2. **丢包率**: 数据传输过程中丢失的数据包比例，越低越好
3. **平均延迟**: 从触控发生到数据被接收的平均时间，越低越好
4. **速度变异系数**: 描述轨迹平滑度，越小越平滑
5. **加速度标准差**: 描述轨迹稳定性的指标，越小越稳定
